# Kia's Wizarding Web
> A responsive Harry Potter themed personal website using HTML and CSS, with integration of AI tools and basic web development.

---

## 🌌 Overview

This website was created to serve as my personal developer portfolio,
highlighting my software and web development projects, technical skills,
and Computer Science journey.

---

## 🛠️ Technologies

| Technology | Purpose |
|---|---|
| **HTML5** | Structuring the website and its content |
| **CSS3** | Styling, layout, and responsive design |
| **Bootstrap** | Responsive layouts and pre-built UI components |
| **VS Code** | Development and code management |
| **Git & GitHub** | Version control and repository management |

---

## ✨ Features

- Responsive design for desktop and mobile
- Carousel images
- About Me section
- AI integration
- Contact section
- Interactive navigation
